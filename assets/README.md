# Assets

Generated by `node scripts/generate-assets.mjs` (no dependencies). Replace any file with final
artwork using the same name and size; `app.json` already points at them.

| File | Use | Size |
|---|---|---|
| `icon.png` | App icon (iOS + general) | 1024 × 1024, no transparency |
| `adaptive-icon.png` | Android adaptive icon foreground (keep content in the center ~66%) | 1024 × 1024 |
| `splash-icon.png` | Splash logo (background color is set in `app.json`) | 512 × 512 |
| `sounds/*.wav` | `tap`, `correct`, `wrong`, `win`, `lose` effects | short clips |

Store-only artwork lives in `/store`.
